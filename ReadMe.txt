Описание скриптов: 

-- Основные скрипты: --
!!! ВАЖНО !!! Все скрипты нужно запускать суперпользователем. Например, так:
sudo ./init.sh

init.sh - начальная установка необходимого ПО
setupZabbix.sh - установка системы мониторинга Zabbix

configServer.sh - настройка сервера (Web + генератор)

*-- Дополнительные скрипты --*

clearning.sh - очистка БД MySQL (удаление таблиц и пользователя)
deploy.sh - развертывание генератора пакетов (back-end)

-- Необходимые файлы

server_sfp_sla.sql - конфигурационный файл БД MySQL
Server_SFP_SLA - бинарный файл генератора пакетов
Server_SFP_SLA.service - конфигурационныйфайл службы
httpServerSLA.tar.gz - исходные файлы web-конфигуратора
