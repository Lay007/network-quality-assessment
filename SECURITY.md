# Security Policy

## Supported Scope

This repository is maintained as a public demonstration and reference implementation. Security fixes should target the current default branch, which is currently `master`.

## Reporting A Vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the repository owner privately and include the affected component, reproduction steps, expected impact, and suggested mitigation if known.

## Secrets

Do not commit real secrets, environment files, private logs, packet captures, or customer-specific configuration. Use example files for placeholders only.
