# Methodology

## Standard Alignment

### RFC 2544
Used for:
- throughput testing
- latency measurement
- frame loss analysis
- burst/back-to-back testing

### ITU-T Y.1564
Used for:
- multi-service testing
- SLA validation
- CIR/EIR verification
- performance under load

## Recommended Test Sequence

1. record configuration and topology
2. verify module reachability
3. verify SNMP availability
4. determine topology / module order
5. run baseline measurements
6. run mode-specific tests
7. record delays, loss and counters
8. store and interpret results
